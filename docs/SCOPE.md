# Scope

Giti.one is a Node.js ERP by Poriya Sayafan.

In memory, every module is `list` / `add`. In PostgreSQL, every module is a row in `erp_row` (`schema.sql`). ISO 9001, 27001, and 55001 records and the PMP map are in `docs/`. Catalog ids are English; CLI and module labels are English and فارسی.

Do not commit `.env`, keys, or customer data.
