# Catalog graph

Public, free. [Open the graph](graph.html).

This is the Giti.one catalog as a graph: which modules **post**, which are **records** with a rule, and which are **slots** (a name with `list` / `add` only).

The picture is generated from `src/graph.js` → `docs/catalog-graph.json`. It is not a hosted ERP and not an AI product.
