# Giti.one ERP

By **Poriya Sayafan**. Public documented information for the [source repository](https://github.com/psayafan/Giti.one-ERP).

This site is **not** an ISO or PMI certificate.

A purchase order is a promise. It is not the books. Receipt and delivery post inventory and a balanced journal. ISO 9001, 27001, and 55001 records and a PMP map live in the same catalog.

## Run

```bash
git clone https://github.com/psayafan/Giti.one-ERP.git
cd Giti.one-ERP
./setup.sh
```

Persian CLI: `./setup.sh --lang fa`
