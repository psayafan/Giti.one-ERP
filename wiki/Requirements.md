# Requirements

What you need to run Giti.one ERP.

| Need | Required |
|---|---|
| Node.js 20 or newer | Yes |
| npm | Yes |
| Git | Yes |
| Docker or Colima | No — only to persist into PostgreSQL |

This tree is a Node.js ERP. Modules are `list` / `add`. Optional PostgreSQL uses one table, `erp_row`. It is not a hosted product, not a certificate, and not a folder of ISO files beside the books.

Local demo Postgres (user / database / password `giti`) is for this demo only. Do not commit `.env`.
