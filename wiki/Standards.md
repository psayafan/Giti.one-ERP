# Standards

How this repository is kept. Not a certificate.

- English for commits and documents. Catalog ids stay English. Labels are English and Persian.
- A module is a row in `src/catalog.js` plus a test. Keep `list` / `add`.
- If it moves money or stock, it posts. Debit equals credit.
- Documents (PO, SO) are not execution. Receipt and delivery are.
- Do not commit secrets.

Public files: `README.md`, `LICENSE`, `SECURITY.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `TRADEMARKS.md`, `SUPPORT.md`, `AGENTS.md`, `docs/`.
