# Security

Report vulnerabilities to **psayafan@hotmail.com**. Do not open a public GitHub issue for a secret, credential, or exploitable bug.

## Scope

This repository is an ERP. Do not send AWS keys, customer data, or production dumps with a report.

## What we will do

1. Acknowledge the mail.
2. Confirm whether the report applies to this tree.
3. Fix in public only after a patch exists, or after you agree the issue is already public.
