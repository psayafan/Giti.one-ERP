# Contributing

By submitting a change you license it under **AGPL-3.0-or-later**.

1. No secrets, `.env`, private keys, or customer data.
2. Add modules in `src/catalog.js`. Run `./setup.sh` or `npm test`.
3. Pull requests against `main`. English for commits and docs.
4. If an AI is writing the change, give it [AGENTS.md](AGENTS.md).
